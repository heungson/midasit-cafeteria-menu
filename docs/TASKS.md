## 남은 결정·확인

1. 실제 계정으로 로그인·목록·이미지 경로 확인(`npm start` 후 설정에서 계정 저장)
2. 직원 계정의 추가 인증 여부 확인 → 로그인 지원 범위 확정
3. 메뉴 이미지를 Claude(외부 API)로 보내는 것에 대한 사내 정책 확인. 불가 시 기본 OCR 전용으로 배포
4. 프로필 배포 방식(사내 채널로 JSON 전달 또는 설치 시 포함한 사내 전용 빌드)
