# PRD — 구내식당 오늘의 메뉴 데스크톱 앱 (MVP)

**요약**: 직원이 macOS 메뉴 막대나 Windows 알림 영역 아이콘을 한 번 눌러 한국 시간 기준 오늘의 아침·점심·건강존·저녁 메뉴와 배식 시간, 층별 식사시간을 한글 텍스트로 확인한다. 메뉴는 그룹웨어의 주간 메뉴 게시물 이미지에서 읽는다.

## 1. 대상과 범위

- **사용자**: 사내망 또는 VPN에 연결된 macOS·Windows 직원 기기
- **원본**: 그룹웨어 게시판의 주간 게시물(제목에 `(M/D~ M/D)` 기간). 본문에 월~금 메뉴 표와 시간 안내가 담긴 PNG
- **포함**: 오늘의 네 가지 식사 구분, 배식 시간, 층별 식사시간, 날짜 일치 보장, 주간 로컬 캐시, 원본 변경 시 재인식, 실패 원인 구분
- **제외(MVP 이후)**: 알림 푸시, 메뉴 평가·검색, 다국어, 추가 인증(OTP) 계정의 자동 로그인

## 2. 기능 요구사항

| ID | 요구사항 | 수용 기준 |
|---|---|---|
| F1 | 아이콘 한 번 클릭으로 오늘 메뉴 표시 | 창이 아이콘 근처에 열리고, 바깥을 누르면 닫힘. Esc로 닫힘 |
| F2 | 한국 시간 기준 '오늘' | 기기 시간대와 무관하게 KST 날짜 사용. 자정(KST)이 지나면 자동으로 다음 날로 전환 |
| F3 | 네 가지 식사 구분 | 아침·점심·건강존·저녁 카드, 섹션(예: 브런치/한식/공통)과 메인(M) 표시. 미제공은 '미제공' |
| F4 | 배식 시간·층별 식사시간 | 식사별 시작–종료·배식 완료 시각, 점심·저녁 층별 시간표 |
| F5 | 날짜 일치 보장 | 열 머리글 날짜가 게시 기간과 맞지 않으면 그 열을 쓰지 않음. 다른 날·다른 주 메뉴를 오늘로 표시하지 않음 |
| F6 | 계정 저장 | 아이디·비밀번호는 macOS 키체인 / Windows 자격 증명 관리자에만 저장 |
| F7 | 이미지 구조화 | 날짜·식사별로 잘라 Claude Code CLI에 이미지로 전달, JSON 스키마 강제 |
| F8 | 대체 인식 | Claude 실패 시 macOS Vision / Windows 한국어 OCR로 재시도 |
| F9 | 캐시·변경 감지 | 주간 결과 로컬 저장, 원본 해시가 바뀌면 재인식, 오프라인이면 캐시 표시 |
| F10 | 상태 구분 | 주말 / 미게시 / 네트워크 단절 / 계정 없음 / 암호 오류 / 없는 사용자 / 추가 인증 필요 / 인식 실패 / 이미지 없음 / 날짜 확인 불가 |

## 3. 비기능 요구사항

- **보안**: 계정은 OS 자격 증명 저장소에만 저장, OCR 엔진에 계정·쿠키·주소 미전달, 그룹웨어 스크립트 미실행, 같은 출처 요청만 허용, 틀린 비밀번호 자동 재시도 금지
- **공개 저장소**: 회사별 접속 정보·실제 메뉴·기기 경로는 저장소와 배포 파일에 포함하지 않음(로컬 프로필로 분리)
- **성능**: 캐시가 있으면 즉시 표시. 새 이미지 인식은 Claude 기준 30초 이내
- **조회 빈도**: 기본 30분 간격(오프라인이면 5분), 창을 열 때 2분 이상 지났으면 확인

## 4. 검증 계획

1. **로그인/조회**: 실제 계정으로 로그인 → 목록 → 게시물 → 이미지 경로 확인. 추가 인증 필요 여부에 따라 로그인 지원 범위 확정
2. **메뉴·시간 정확성**: 실제 주간 이미지별 기대값(로컬 전용)과 비교. 기준 주: 화 아침 2개 항목, 화 점심 1개 항목, 금 저녁 미제공, 배식 시간 3종, 층별 시간
3. **오프라인 캐시**: 네트워크 차단 시 이번 주 캐시 표시, 지난주 캐시는 오늘로 표시하지 않음
4. **양 플랫폼**: macOS(arm64·x64), Windows 10/11에서 설치·아이콘·키체인/자격 증명 관리자·기본 OCR 동작

## 5. 미검증 위험

| 위험 | 대응 |
|---|---|
| 실제 계정 로그인 미검증 | 프로필로 폼 필드·경로 조정, 계정 없이 확인 가능한 항목은 `verify:live`로 점검 |
| 추가 인증 계정 | 감지 후 안내. 지원 범위는 계정 확인 후 결정 |
| Claude 인식 정확도 | 기본 OCR 대조 일치율 경고, 실제 이미지 누적 검증 |
| 표 양식 변경 | 격자 인식 실패 시 '인식 실패'로 표시(잘못된 메뉴 표시 방지) |
